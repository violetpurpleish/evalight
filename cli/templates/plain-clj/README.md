# my-app

A JVM Clojure project. The entry point is `src/my/app.clj`.

- `evalight run` runs the application with `clojure -M:run`.
- `evalight dev` opens the local Evalight workshop with a JVM REPL.
- `evalight test` runs namespaces ending in `-test` under `test/`.

Use the Clojure CLI and a JDK. The workshop also needs Bun.
