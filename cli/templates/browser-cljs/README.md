# my-app

A browser ClojureScript project with the Evalight component gallery.
Edit `src/app/core.cljs` and `src/app/gallery.cljs` to change the page.

- `evalight run` serves the app at http://localhost:3456 with hot reload.
- `evalight dev` starts the app and opens the local Evalight workshop.
- `evalight test` compiles and runs namespaces ending in `-test` under `test/`.
- `bun run release` compiles optimized JavaScript into `public/js/`.

Use Bun and a JDK.
